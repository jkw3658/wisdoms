# wisdoms

Google スプレッドシートにまとめたノウハウ・格言を、Android のホーム画面ウィジェットにランダム表示するアプリです。

- ホーム画面ウィジェットに 1 つずつ表示（タップで次の言葉へ、◀ で 1 つ前に戻る）
- 山札方式のシャッフルで、一巡するまで同じ言葉は出ません
- カテゴリを選んで表示対象を絞り込めます
- ウィジェットのチェックボックスで、シートの「チェック」列にチェックを書き込めます
- シートは**非公開のまま**、Google Apps Script 経由で読み込みます（1 日 1 回自動更新、オフラインでもキャッシュで表示）

## 1. スプレッドシートの準備

1 行目を見出しにして、次のような列を作ります（列の順番は自由です）。

| 本文 | カテゴリ | 出典 | チェック |
| --- | --- | --- | --- |
| 急がば回れ | ことわざ | | ☐ |
| 計測できないものは改善できない | 仕事術 | ドラッカー | ☑ |

- `本文` 列（`言葉` `格言` `テキスト` `text` でも可）：表示する言葉。見つからない場合は A 列
- `カテゴリ` 列（`カテゴリー` `分類` `category` でも可）：見つからない場合は B 列
- `出典` 列（`作者` `人物` `source` `author` でも可）：省略可
- `チェック` 列（`check` でも可）：ウィジェットでチェックしたときに書き込まれる列。省略可。**挿入 → チェックボックス** でチェックボックスにしておくと見やすくなります

## 2. Apps Script を設定する

1. スプレッドシートを開き、メニューの **拡張機能 → Apps Script** を選ぶ
2. 最初からある `コード.gs` の中身を、このリポジトリの [`apps-script/Code.gs`](apps-script/Code.gs) の内容で置き換える
3. `TOKEN` を推測されにくい長い文字列（例：パスワード生成ツールで作った 32 文字程度）に書き換えて保存
4. 右上の **デプロイ → 新しいデプロイ** を選び、種類で **ウェブアプリ** を選択
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. **デプロイ** を押し、アクセスを承認する（「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える

> **スクリプトを更新するとき**（チェック機能の追加など）：`コード.gs` を新しい内容に置き換え、`TOKEN` を以前と同じ値に書き直して保存します。
> その後 **デプロイ → デプロイを管理 → 鉛筆アイコン（編集）→ バージョン：新バージョン → デプロイ** を押します。URL は変わらないので、アプリの設定はそのままで使えます。

> 「全員」にしても、シート自体は公開されません。URL と TOKEN の両方を知っている人だけが内容を取得できます。

## 3. アプリをインストールする

1. スマホのブラウザで次のリンクを開くと、最新版の APK が直接ダウンロードされます
   https://github.com/jkw3658/wisdoms/releases/latest/download/wisdoms.apk
2. ダウンロードした `wisdoms.apk` を開いてインストール（「提供元不明のアプリ」の許可を求められたら許可）

`main` ブランチに変更が入るたびに自動でビルドされ、同じリンクが最新版に置き換わります。
アップデートも同じリンクからダウンロードして上書きインストールするだけです。

## 4. 使い方

1. アプリを開き、「シートの接続」に手順 2 の URL と TOKEN を入力して **保存して読み込む**
2. ホーム画面の空いている所を長押し →「ウィジェット」→「格言」を配置
3. 必要に応じて、アプリで表示するカテゴリを選ぶ

シートに言葉を追加した場合、1 日以内に自動で反映されます。すぐ反映したいときはアプリの「シートから再読み込み」を押してください。

## アップデートを上書きインストールしたい場合（任意）

署名鍵を登録しないと、ビルドのたびに署名が変わり、新しい APK を上書きインストールできません（一度アンインストールが必要になり、設定も消えます）。
固定の署名鍵を使うには、PC で一度だけ鍵を作り、GitHub に登録します。

```sh
keytool -genkeypair -v -keystore release.jks -alias wisdoms -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # macOS は base64 -i release.jks
```

リポジトリの **Settings → Secrets and variables → Actions** に次の 4 つを登録します。

| 名前 | 値 |
| --- | --- |
| `KEYSTORE_BASE64` | 上の base64 の出力 |
| `KEYSTORE_PASSWORD` | 鍵ストアのパスワード |
| `KEY_ALIAS` | `wisdoms` |
| `KEY_PASSWORD` | 鍵のパスワード |

`release.jks` はリポジトリに含めず、手元に保管してください。

## 構成

- `apps-script/Code.gs` … シートを JSON で返す Apps Script
- `app/` … Android アプリ（Kotlin / Jetpack Compose / Glance ウィジェット / WorkManager）
- `.github/workflows/build.yml` … APK をビルドする GitHub Actions
